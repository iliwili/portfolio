# Ilias.dev — Portfolio

A minimalist, developer‑first portfolio powered by **Nuxt 3 + TailwindCSS**.


## Quick start
```bash
npm install
npm run dev # http://localhost:3000
```


## Build
```bash
npm run build && npm run start
```


## Customize
- Edit content in `pages/index.vue` and `components/*`.
- Replace links (email, LinkedIn, GitHub) in the Contact section.
- Add project screenshots by swapping the placeholder in `<ProjectCard />`.


## Tech
- Nuxt 3, TailwindCSS
- Inter (UI) + JetBrains Mono (code accent)
